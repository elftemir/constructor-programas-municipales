# data

`municipios_ine.csv` incluido aquí es **solo una muestra de desarrollo** para probar el esquema y el autocompletado. Antes de una versión distribuible debe sustituirse por la relación completa vigente del INE, manteniendo las columnas `codigo_ine,nombre,provincia,comunidad_autonoma`.

Fuente prevista: Instituto Nacional de Estadística, «Relación de municipios y sus códigos por provincias». No inventar ni completar el listado manualmente.

`catalogo_marco.json` y `catalogo_validacion.html` serán generados por Antigravity a partir del programa marco.
